# RPG Resource-Economy Review

サバイバル・RPGが主構造、またはHP・消耗品・装備・戦闘・資源管理を主要判断として約束する作品にだけ適用する数値監査。

RPGを名乗る作品で資源経済が成立していない場合、このパックをN/Aにして回避してはならない。変数や戦闘演出が存在するだけでなく、資源の配分判断が実際の攻略に必要かを検査する。

根拠は [survival_rpg.md](../../ink-scenario-creator/references/genres/survival_rpg.md) と [survival_rpg_gimmicks.md §5〜§9](../../ink-scenario-creator/references/survival_rpg_gimmicks.md)。

## 1. 主資源と基本式

最初に、作品の主資源を宣言する。HPでない場合も、油・時間・体温など道中を通して燃える資源へ同じ式を適用する。

```text
通行料 = 正解装備・ノーミスの必須戦闘・必須危険の主資源消費合計
設計条件: 通行料 > 開始主資源
余剰マージン =
  開始主資源
  + 携行回復量 × 入手可能数
  - 通行料
  - 想定ミスの消費量
```

数値は作品ごとに式から導出する。worked exampleの値をコピーしない。

## 2. 資源台帳

感覚的な「難しい」「簡単」ではなく、次を数値で埋める。

| 開始主資源 | 必須通行料 | 回復量 | 回復入手数 | 回復込み総供給 | 想定ミス1回のコスト | 吸収可能ミス数 | 最終余剰マージン |
|---:|---:|---:|---:|---:|---:|---:|---:|

追加で記録する。

- 必須経路に含めた戦闘・危険
- 任意寄り道のコスト
- 回復を入手する位置
- 回復を初めて必要とする位置
- 決戦前の主資源・回復数

### 合格の基本形

- 正解装備・ノーミスでも携行回復を最低1回使う。
- 想定した数回の初見ミスを、供給全量で吸収できる。
- ごり押しでは主資源が尽きる。
- 主資源枯渇後も敗北EDへ到達でき、ソフトロックしない。
- 余剰マージンを被弾・失敗何回分かで説明できる。

### 重大な失敗

- 最適な必須経路の通行料が0または開始資源より十分小さく、携行回復が一度も必要ない。
- 戦闘・危険をすべて無料のクラス専用解答で回避できる。
- 回復材が表示されるだけで、使用時点の配分判断がない。
- ボスまで無傷・回復未使用で到達し、そのまま勝利できる。

## 3. プレイヤー類型別の時刻表

階層・エリアごとに残主資源と回復数を追う。

| 類型 | エリア1後 | エリア2後 | エリア3後 | 決戦前 | 最終結果 |
|---|---:|---:|---:|---:|---|

最低限、次を作る。

### ノーミス

- 正しい観察と装備選択をする。
- 不要な失敗をしない。
- それでも携行回復が最低1回必要か。

### 初見

- 事前に予測した数回のミスをする。
- 供給全量を、時刻表で想定した使用地点へ配分すれば生還できるか。
- 一つの通常ミスだけで即座にクリア不能にならないか。

### ごり押し

- 警告を無視する。
- 不適切な装備で挑む。
- 同じ失敗を繰り返す。
- 資源が尽き、終端の敗北EDへ落ちるか。

### リスク購入

- 早い段階で購入する。
- 弱ってから購入する。
- 購入しない。
- 購入後の関門でミスする。

### 単調性

同じ事前状態なら、情報を理解したプレイが無情報・雑なプレイより悪い残資源になってはならない。

```text
賢いプレイの残資源 >= 初見プレイの残資源 > ごり押しの残資源
```

ムーンウォーター等の特別資源を使った方が無料のクラス解法より悪く、さらに真EDを失う、といった逆転は単調性違反または支配された選択として指摘する。

## 4. 資源の役割

各資源に固有の役割があるか確認する。

| 資源 | 役割 |
|---|---|
| 携行回復 | どこで使うかという配分判断 |
| 据え置き回復 | 解毒・状態解除など役割限定の節目 |
| 恒久軽減 | 以後の未知の失敗単価を下げる保険 |
| 主資源 | 道中全体を通して燃える燃料 |

次を指摘する。

- 携行回復が潤沢すぎて、いつ使っても余る。
- 据え置き回復が汎用全回復になり、携行回復を不要にする。
- 決戦直前の無条件全回復が、それ以前の収支を消す。
- 防具や軽減により、予兆つき失敗のコストが0になる。
- 複数の回復源が同じ役割を持ち、一方が不要になる。
- 無消費の特殊技・連携技・クラス専用正解が通常戦闘と回復を不要にする。

恒久軽減があっても、失敗コストは**最低1**を通す。

## 5. 供給は前積み

回復材を必要になる直前に渡すjust-in-time供給は、配分判断を殺す。

確認する。

- 序盤〜中盤で回復材を入手する。
- 後半に向けて供給が絞られ、温存判断が生まれる。
- ボス直前に必要数を保証配布していない。
- 入手時点では、どこで使うのが最適か一意に決まっていない。

供給位置、入手量、最初の必要位置を並べ、プレイヤーが複数区間を見越して配分する構造になっているかを評価する。

## 6. リスク選択

前進のコストを、複数の資源のどちらで払うか選ばせる。

### 必須条件

- どちらの選択肢でも前進できる。
- 両方に実在するコストがある。
- 一方が実質的な即死罠ではない。
- 一方が無料の安全ルートではない。
- 支払い資源が尽きている場合の挙動が定義されている。
- 尽きた資源の支払いを無料化せず、別資源へ振り替えるか選択を塞ぐ。
- コストの種類が選択前に世界内で示唆される。
- コストは決定論的な固定値である。

「時間」は、コマンド入力や手数が実際に油・潮位・期限等を消費する作品でだけ対価になる。時計も消費もない作品で「遠回りは時間がかかる」と書いても、プレイヤーの資源コストではない。

## 7. リスク購入

防具・恒久バフ等の永続強化を、代償と引き換えに買わせる場合に確認する。

1. **支払いが先、回収が後**：購入場所と解消手段の間に本物の関門がある。
2. **現在状態に比例**：現在HP半減等、購入タイミングが判断になる。
3. **期待値がほぼ中立**：明確な得なら正解、明確な損なら罠であり、選択にならない。
4. **価値は分散圧縮**：未知の追加ミスを軽くする保険として働く。
5. **最低1**：軽減後も失敗コストを0にしない。
6. **購入前警告**：回復封印や解消条件があることを、購入前に現場で読める。

比較表を作る。

| 経路 | 購入時支払い | 後続の想定被害 | 合計 | 分散・追加ミス耐性 | 判定 |
|---|---:|---:|---:|---|---|
| 購入なし | | | | | |
| 購入あり | | | | | |

警告を観察しなくても購入できる、または購入後に初めて代償が分かる場合はフェアネス違反として扱う。

## 8. 階層・エリア台帳

各階層を次の表で管理する。

| 階層 | 必須敵・危険 | 通行料 | 補給 | 回復なし累積 | 必須アイテム・ヒントの取得→使用 |
|---|---|---:|---:|---:|---|

確認する。

- 必須アイテム・ヒントの取得階と使用階の**階差は2まで**。
- 回復なし累積主資源が0を割る位置は終盤にある。
- 弱い状態では先へ進めない成長ゲートがある。
- ざこは資源を削る。
- 中ボスは前提ゲートと成長報酬を担う。
- ラスボスはそれまでの要素を収束する。
- 内容の薄い階層を、数合わせで追加していない。
- 各階層に場所・目的・脅威・必要入力・報酬・次階層への動機がある。

## 9. スモークプレイと数値焼き込み

文章上の収支表だけでなく、シナリオテストまたは再現可能な操作列で代表値を検証する。

最低限のケース：

- 必須装備なしでは前提ゲートに勝てない。
- 必須装備ありでは勝てる。
- 通常ルートで携行回復を最低1回使う。
- 初見相当のミスを供給範囲で吸収できる。
- ごり押しで主資源が尽きる。
- 主資源枯渇後に敗北EDへ到達できる。
- 最悪プレイでもソフトロックしない。
- 決戦直前の無条件全回復がない。
- 恒久軽減後も予兆つき失敗コストが最低1ある。
- リスク購入直後と関門通過後の代表資源値が期待どおりである。
- 各階層終了時の代表HP・回復数が時刻表と一致する。

テストが存在しない場合は、コンパイル成功を代用せず `MISSING` と報告する。

## 10. 重大度

- **Blocker候補**：資源枯渇からEDへ到達不能、主要前提ゲートが装備なしで突破可能、数値条件のため正規経路が到達不能。
- **Major候補**：必須通行料が開始資源以下で回復不要、無料解答が経済を消す、決戦前全回復、無警告リスク購入、資源役割の重複。
- **Moderate候補**：余剰マージンの局所的な過不足、供給位置の偏り、類型間の小さな単調性逆転。

「バランスが悪い」で終わらせず、式、経路、残資源、プレイヤー判断への影響を示す。
